## 依賴關係

```
platform-api  ←(compileOnly)── paper-api 1.21.4
platform-api  ←(api)───────── platform-core ←(compileOnly) paper-api
platform-core ←(implementation) javalin-bundle 6.6.0, gson 2.11.0, sqlite-jdbc 3.53.2.1
platform-core ←(testImplementation) paper-api, assertj-core 3.26.3
platform-core ←(testAppsCompileOnly) platform-api + paper-api（fixture App 類別）
platform-core ←(plugin) com.gradleup.shadow 9.6.1
apps:hello-app ←(compileOnly) platform-api
apps:hello-app ←(testImplementation) platform-api, paper-api, sqlite-jdbc, junit-bom
```

## 各檔案/資料夾用途

| 路徑 | 用途 |
|------|------|
| platform-api/ | App 開發者面對的 API（不可變契約，不含實作） |
| platform-core/ | 平台核心實作（AuthManager、AppContainer、WebServer 等） |
| platform-core S12rytPlugin.java | Paper plugin 進入點（薄封裝，零指令） |
| platform-core PlatformBootstrap.java | 平台生命週期管理（startup/shutdown，不依賴 JavaPlugin） |
| platform-core AppContainer.java | App 容器：掃描/隔離/熱載/卸載 |
| platform-core AppServices.java | 平台服務接縫（解耦 AppContainer 與 Bukkit/Javalin） |
| platform-core PlatformAppServices.java | AppServices 平台實作（組裝 7 依賴 + getLogger） |
| platform-core AppContextImpl.java | AppContext 實作（組裝所有 App 能力，close 關閉元件） |
| platform-core AppRouterRegistry.java | 路由註冊表（match/clear，不依賴 Javalin） |
| platform-core AppStorageImpl.java | 每 App 獨立 SQLite（apps/{appId}/data.db） |
| platform-core AppLoggerImpl.java | ring buffer 500 + 檔案持久化 |
| platform-core AppSchedulerImpl.java | 守護線程池排程器（Supplier<Plugin> 注入） |
| platform-core AppConfigImpl.java | Properties 基底配置（load(file)，線程安全） |
| platform-core AuthManager.java | 密碼初始化 + token 認證 |
| platform-core WebServer.java | Javalin 6 內嵌（API + 靜態檔案 + App 路由分派） |
| platform-core web-console/ | Vue 3 + Vite 前端（dist 打包進 jar） |
| platform-core src/testApps/ | 測試 fixture App 類別（獨立 source set，打成 jar 供 ClassLoader 測試） |
| apps/hello-app/ | 示範 App（展示路由+storage+scheduler+logger） |
| agent/ | 專案記錄與 TDD 驗收標準 |
